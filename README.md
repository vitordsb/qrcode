# Gerador de QR Code

Converte em segundos seu texto em um QR Code.
Feito em JavaScript, HTML e Sass, usando a API de QR Code da [goqr.me](https://goqr.me/api/).

Por **Vitor** ([@vitordsb](https://github.com/vitordsb)).

### Como usar
- Abra o `index.html` no navegador
- Escreva seu texto (URL, e-mail, telefone)
- Clique em "Gerar QRcode"
- Para salvar, clique com o botão direito na imagem e escolha "Salvar imagem como"
- Para apagar, clique em "Resetar"
